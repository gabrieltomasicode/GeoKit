# 🌍 GeoKit: Ferramentas Utilitárias para Dados Geocientíficos

O **GeoKit** reúne notebooks práticos para acelerar rotinas de tratamento, integração e visualização de dados geocientíficos, com foco em uso aplicado no dia a dia técnico.

## Notebooks disponíveis

- **Geochem_Grid_Resampler.ipynb**  
  Ferramenta para reamostragem/interpolação de dados geoquímicos em grid regular (ex.: 15 cm), útil para padronizar intervalos e preparar bases para comparação entre poços, modelagem e controle de qualidade.

- **GeochemLOD_Processor.ipynb**  
  Ferramenta para processamento de dados geoquímicos com tratamento de limites de detecção (LOD), limpeza e padronização de colunas, servindo para deixar os dados prontos para análises estatísticas e interpretação confiável.

- **Scatter_to_well_log.ipynb**  
  Ferramenta de visualização interativa que transforma dados tabulares/scatter em perfis estilo well log, facilitando análise exploratória, correlação de curvas e leitura integrada por poço.

- **LithoLAS_Integrator.ipynb**  
  Ferramenta para integrar intervalos litológicos com arquivos LAS, interpolando e exportando resultados de forma robusta, ideal para enriquecer perfis de poço e apoiar interpretação geológica.

## Recomendação de execução

Para melhor funcionamento, o ideal é baixar os notebooks e executá-los no **Google Colab**, onde o ambiente já favorece instalação de dependências, uso de widgets interativos e integração com o Google Drive para leitura/escrita de dados.
